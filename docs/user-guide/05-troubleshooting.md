# 排错和反馈

## 导出诊断包

设置 → 诊断 →「导出诊断包」，或在出错的运行页点「诊断包」（会额外带上这次运行的 `.nextflow.log`、控制台输出、配置和任务列表）。
得到一个 `.tar.gz`，反馈问题时附上即可。包里的 API key、token、代理密码都已替换为「‹已隐藏›」，不包含结果文件和 work 目录。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 顶栏显示「未就绪」 | 点它进入运行环境页，按提示安装缺的工具 |
| 笔记本提示没有内核 | 运行环境页「创建笔记本环境」，或 `python3 -m pip install ipykernel` |
| R 笔记本只能编辑 | 在 R 里运行 `install.packages("IRkernel"); IRkernel::installspec()` |
| `.h5ad` 摘要读取失败 | 笔记本用的 Python 里需要 `h5py`（scanpy 自带） |
| 结构显示「浏览器不支持 WebGL」 | 更新显卡驱动；Linux 远程桌面下可能没有 WebGL |
| 打开项目时提示由更新版本创建 | 这个项目用更新的应用保存过；请升级应用，项目不会被改动 |
| 运行停在「准备中」 | 设置 → 诊断导出诊断包，看 `logs/app/runner.log` |
| 集群上的运行出问题 | 见[在集群和云上运行](06-clusters-and-cloud.md#常见问题) |

## 升级后看不到以前的项目

应用的内部数据库没有迁移，格式变化时桌面版会重建「最近项目」列表，项目文件夹本身不动：用「打开项目」重新打开即可。
项目化之前的旧版本把流程和模块存在数据目录的 `studio.sqlite` 里；打开项目后首页会提议导入：流程进 `workflows/旧版导入/`，模块进 `modules/`，旧数据库保持不变。
