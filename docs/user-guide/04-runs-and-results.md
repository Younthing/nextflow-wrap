# 运行、结果和磁盘

## 运行

- **运行环境**：Shell 用本机已有的软件；conda / mamba 按模块声明的环境创建；Docker 用模块的镜像。默认 CPU、内存和引擎在 设置 → 偏好 里改。
- **续跑**：画布有可续跑的上一次运行时，运行对话框里会出现「续跑」，相当于 `nextflow run -resume`，没变的任务直接用缓存。
- **通知**：设置 → 偏好 里打开「运行完成或失败时发系统通知」后，运行成功或失败时发系统通知（网页版需要允许浏览器通知）。
- **关窗**：运行时关闭窗口，应用留在菜单栏继续跑。

## 结果

结果页按模块列出发布到 `--outdir` 的文件：图片、PDF、HTML 报告、CSV/TSV 表格、Markdown、`.h5ad` 摘要、PDB/PDBQT/SDF/mmCIF 结构（Mol*）都能直接预览。
每个文件都能追溯到产生它的节点、模块版本、笔记本修订和任务；「带回笔记本」复制一段读取代码。

## 磁盘

Nextflow 把每个任务的中间文件留在流程共享的 `work/` 目录里，所以清理按**一次 Nextflow 会话**进行（一次运行和它的所有续跑共享一个会话）。

设置 → 磁盘 列出每个会话占用的空间和可回收的空间：

- 「清理」删除这个会话独有的 work 目录和缓存，其他会话还在用的文件保留。清理后这次运行不能再续跑。
- 打开「同时删除这些运行的结果」会一并删除 `--outdir` 里的文件。
- 正在运行的会话不能清理。
