# Nextflow Studio 用户指南

Nextflow Studio 把 Jupyter 笔记本里的分析步骤发布成模块，在画布上连成流程，再交给 Nextflow 在本机运行。
这份指南面向桌面版（macOS / Linux），网页版用法相同，只是没有原生文件对话框、菜单栏图标和系统通知。

1. [安装和首次启动](01-install.md)
2. [第一课：单细胞（PBMC 3k）](02-lesson-single-cell.md)
3. [第二课：分子对接（AutoDock Vina）](03-lesson-docking.md)
4. [运行、结果和磁盘](04-runs-and-results.md)
5. [排错和反馈](05-troubleshooting.md)

两节课用的是同一套操作：在笔记本里写好并跑通代码 → 标出输入和输出 → 发布为模块（会先试跑一次）→ 在画布上连接 → 运行 → 在结果页查看。
第一课处理表达矩阵，第二课处理分子结构；做完任意一课就掌握了全部基本操作。
